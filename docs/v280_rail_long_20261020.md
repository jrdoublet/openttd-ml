### Classement causal et limites

1. **Portée amont démontrée, levier plausible** : parmi les neuf sources
   exactement identifiées (7/1234), cinq n'ont aucune pose à leur source et une
   paire AAA hors portée : ferme 1234/7 (161), 1234/33 (245), 1234/47 (266),
   forêt 7/23 (330), usine 7/27 (304 entre gares). Elles représentent
   **1702348 £** chez AAA. Trois sont aussi au-delà de V269=250 : **1542965 £**.
   Le fait d'attendre 1975 ET le vivier vide n'offre pas les mêmes choix lors
   des premières poses. Les bornes sont vérifiées dans `OpexMakeCandidate` ; le
   fret parcourt tous ses puits, sans la grille spatiale réservée au pax.
2. **Exclusivité des origines** : quatre des neuf sources exactes ont été
   engagées ailleurs (1 départ court, 3 arrivées de matières premières), soit
   **1259519 £** de profit AAA. Les trois arrivées bloquent un autre cargo,
   pas un second transport de la même production. Le mécanisme est distinct,
   mais une extension ne doit pas simplement desserrer C55 : il faudrait aussi
   qualifier une vraie jointure et l'export de transformateur (V233/V218).
3. **Échecs d'exécution d'une alternative courte** : 8/8 tentatives de l'usine
   7/27 échouent, dont 6 `NOTRAIN`, pas six plafonnements A*. On ne réduit pas
   ces événements à « TRKFAIL / budget pathfinder ». Ils concernent une autre
   destination que celle d'AAA ; augmenter les itérations ne corrige pas
   l'échec d'achat/assemblage du train. Aucun budget A* changé dans V280.
4. **Classement/financement** : pas de preuve qu'ils soient la cause première
   des paires exclues avant économie. C70 calibre le **numérateur** ; le score
   global est `OpexProjectScore(OpexProjectFundProfit(project), max(K_dec,
   capital_financé))` (hors exemptions flotte). Il ne faut pas le décrire comme
   un simple ROI fixe ; la mémoire `aaahogex_denominateur_variable` est
   historique et les sources courantes font foi. Les logs de l'usine 7/27
   montrent sélection et financement effectifs. Les bornes V177 portent sur
   le pax, pas ce fret. V178/V179 sont à 1 sur la base courante : ils gardent
   certaines destinations servies, jamais une source déjà servie ; le chemin
   ville conserve son propre test `ss != null || st != null`.

Ces catégories se recouvrent dans le pipeline : une paire peut être à la fois
hors portée et desservie. Les 7 sources de graine 42 ne sont pas ajoutées aux
comptes exacts. Pas de nouvelle qualification économique ; le constat V267
n'est pas rejoué. C55 a été relu dans la mémoire `c55_filtre_origine_nul` et
les journaux des 13/09 et 22/09 : aucun relâchement général d'origine prévu.
