TrainLineAI — pair_rank difficulty gradient

100 attempts, 5 seeds (different maps) × 20 town-pair ranks each. Every candidate town pair on a map is scored (population_a × population_b / distance — the heuristic that already fixed most NOPATH failures) and sorted best-first; pair_rank (new AI parameter) picks that pair directly by index instead of the old auto-retry loop that quietly fell back to the next pair on failure. Rank 0 is always the best-scoring pair. Ranks are sampled from a geometric distribution rather than swept uniformly, so the budget is spent densifying the feasible/infeasible boundary instead of on far-tail pairs almost guaranteed to fail. num_trains=2 / wagons_per_train=2 / engine_rank=1 held fixed to isolate this one axis. Each attempt now gets exactly one preflight, no fallback — a failure at a given rank is a real data point about that rank, not hidden by retrying a better pair.
