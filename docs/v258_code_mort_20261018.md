# V258 — Retrait du code mort issu des constantes figées (2026-10-18)

## Contexte et objectif

Le lot V236 et les lots de simplification associés ont figé une série de réglages en constantes
globales en majuscules (définies dans `ai/OpexAI/globals_pre.nut` et déclarées dans `ai/OpexAI/settings.nut`),
qui ne sont plus exposées via `info.nut`.

Certaines branches conditionnelles du code étaient devenues strictement inatteignables (mortes) en
raison de la valeur figée de ces constantes.
La mission V258 consiste à retirer ces branches mortes sans aucune altération de comportement, en
préservant les constantes elles-mêmes si elles sont référencées ailleurs.
