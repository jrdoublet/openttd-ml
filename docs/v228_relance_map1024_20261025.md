**25 octobre 2026 — pré-enregistrement descriptif, sans variante ni adoption.**

Le volet V228 sur carte 1024² du 19/10 est **invalide** : l'IA se figeait
avant V276. Les résultats V276/V278 ont depuis été qualifiés sous un code
et un protocole distincts ; ils ne réparent pas rétroactivement ce volet.
L'objet de cette reprise est de mesurer le défaut actuel sur deux cartes,
avec le même bundle OpexAI/AAAHogEx, les mêmes graines et le même horizon.
