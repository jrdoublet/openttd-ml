## Méthode, unités et limites

- Réglages : tous les `AddSetting` de `ai/OpexAI/info.nut` correspondant aux suffixes/préfixes demandés, plus `air_roi_renfort1_itt`, `v307_probe_year` et `v307_abnd_autopsy` parce qu'ils pilotent des mesures connexes. Datation : première introduction de **la déclaration précise**, vérifiée avec `git log --reverse -S<nom> -- ai/OpexAI/info.nut` et, pour `probes`, `git show` du commit créateur (la recherche du mot « probes » seul donne un faux positif dans une description antérieure). `local*` signifie que `git log -S` ne peut pas attribuer de hash à la déclaration présente dans le travail non commité. Les fichiers déplacés et l'introduction de flags internes plus anciens ne sont pas assimilés à une nouvelle sonde. Le snapshot `docs/inventaire_parametres_20261022.md` mentionne **103 AddSetting avant les nettoyages** et ne suffit pas pour inventorier l'interface actuelle.
- Journal : `OpexDecide(kind, fields)` produit `AILog.Info("OPEX AAAA-M-J KIND champs")` (`probes.nut:42-54`) et peut précéder un événement de `TASK name=…`. Les `AILog.Info` directement émis peuvent avoir **un autre préfixe** et ne passent pas par `OpexDecide`. `OpexSign` construit un panneau OpenTTD après troncature du nom à **31 caractères** (`probes.nut:36-40`) ; les panneaux constituent une mesure de référence lue par les bancs (`CLAUDE.md`, « Mesure »).
- Consommation : **L** = lecteur de traces/mesures vérifiable dans `sweeps/` actif ; **P** = producteur de campagne qui arme le réglage mais ne parse pas forcément la sortie ; **T** = test de contrat qui vérifie le code ou la sortie (pas une consommation de données de campagne) ; **A** = `sweeps/archive/` ou `docs/` seulement. Un script qui contient le nom du réglage n'est **pas**, à lui seul, un lecteur des données. Les fichiers localement supprimés ou encore non suivis par Git sont qualifiés comme tels.
- « Coût défaut » désigne le chemin exécuté avec tous les réglages à leur valeur livrée, pas un budget mesuré : **0** = travail de collecte protégé par un drapeau faux (la lecture/garde elle-même subsiste), **non nul** = panneaux, appels ou chemin opérationnel actifs ; **conditionnel** = mesure ou log actif si un autre drapeau l'arme. L'activation des groupes peut modifier opcodes/ticks et donc les trajectoires ; **aucune équivalence économique n'est déduite de l'identité des champs**.
- « Lignes supprimables » = ordre de grandeur de lignes de code potentiellement retirables **après** validation et correction des tests/consommateurs, sans dédoublement des lignes partagées. `~5–10` pour un simple `AddSetting` et son chargement ; enlever une instrumentation complète coûterait beaucoup plus et exige une décision distincte. Les plages sont indicatives, pas un patch.
