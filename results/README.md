# Résultats d'expériences

Ce répertoire contient les artefacts machine des bancs, diagnostics et smokes : JSON finaux et
checkpoints JSONL associés. Ils ne font pas partie de la documentation narrative.

Les scripts de production restent dans `sweeps/`; leurs sorties par défaut sont écrites ici.
Les analyses et décisions qui citent un résultat restent dans `docs/` et référencent son fichier
correspondant sous `results/`.
