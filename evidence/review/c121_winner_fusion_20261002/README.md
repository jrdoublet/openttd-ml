# Fusion du gagnant AIR : audit dérivé du 2 octobre

`summary.json` conserve le verdict brut, la règle de neutralité déclarée avant
mesure, les contrôles finaux, les deltas des vingt graines et les hashes des
rapports/manifeste/plan/smoke. C'est un audit compact ; il ne remplace pas les
preuves brutes conservées dans `results/` et ne modifie pas l'index historique.

La décision porte sur `c121_air_winner_fusion=1` lorsque C121 est utilisé,
pas sur l'adoption du modèle économique C121. Le point estimé de profit est
négatif ; l'acceptation suit la règle d'absence de perte détectée définie pour
les optimisations d'opcodes, sans prétendre démontrer une égalité des profits.

Le script d'audit exécuté est retenu dans le dossier de campagne :
`results/c121_winner_economics/20261002_neutrality_r1/audit_final.py`.
